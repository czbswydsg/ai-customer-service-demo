# 电商AI客服质检测评工作台 V1.1

这是把《电商AI客服质检测评用例集 V1.1》结构化后的可运行静态前端。

## 文件
- `index.html`：评测工作台首页，读取JSON并展示总览、Case、详情、知识库与Badcase分类。
- `evaluation-set-v1.1.json`：唯一数据源，包含50条Case、Ground Truth来源、评分、判定、知识库与统计。
- `schema.json`：数据结构约束。
- `validator.js`：浏览器端数据与评分一致性校验。
- `statistics.js`：统计计算逻辑。

## 数据原则
前端不生成、不随机补齐、不修改Case数据；页面读取JSON中的结构化内容。评分公式为“六项原始分之和 ÷ 120 × 100”。判定为“总分<75 或 高严重度错误=是 → 错误”。

## 运行
直接双击 `index.html` 即可查看预览。部分浏览器出于本地文件跨域限制可能无法读取JSON，此时请用任意静态服务器启动，例如：

```bash
python -m http.server 8000
```
然后访问 `http://localhost:8000/`。

## 诚实说明
数据仅来自本次提供的V1.1 Markdown内容，不代表真实企业客服数据。项目策略类规则被明确标为“项目策略”，不伪装成法律法规。
